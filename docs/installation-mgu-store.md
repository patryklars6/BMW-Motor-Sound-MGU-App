# Installation und Update im MGU Store

Die vollständige Anleitung steht direkt in der [README](../README.md#installation-und-update-über-den-mgu-store).

Für Version **0.2.2** die bestehende Quelle auf dem Branch `codex/luxo-sound-tuning-020` aktualisieren und **LUXO Motor Sound → Aktualisieren** wählen. Bei einer bisher fehlgeschlagenen Erstinstallation **Installieren** wählen. Der Audio-Dienst **0.2.2** wird als Abhängigkeit mitgeliefert. Ausstehende Dienste werden entsprechend der Store-Meldung beim nächsten regulären MGU-Start aktiv.
