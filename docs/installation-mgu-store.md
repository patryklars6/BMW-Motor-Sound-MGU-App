# Installation und Update im MGU Store

Die vollständige Anleitung steht direkt in der [README](../README.md#installation-und-update-über-den-mgu-store).

Für das Update von 0.2.0 auf 0.2.1 die bestehende Quelle auf dem Branch `codex/luxo-sound-tuning-020` aktualisieren und **LUXO Motor Sound → Aktualisieren** wählen. Der Audio-Dienst wird als Abhängigkeit mitgeliefert. Ausstehende Dienste werden entsprechend der Store-Meldung beim nächsten regulären MGU-Start aktiv.
